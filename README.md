# blixuAddons

A Fabric client mod for Minecraft 26.2 and Hypixel SkyBlock: GLSL glows and designs, cosmetics,
slayer visuals (Voidgloom), HUD elements, damage tags, trajectories, CS-style item inspects and a
performance engine that works alongside Sodium.

## Building

```bash
./gradlew build
```

The mod jar is written to `build/libs/`. Requires Java 25.
